## What was built
Three tools combined into one site, as requested:

1. **Identify font from image** (`/font-identifier-from-image/`) — targets "font identifier from image"
   (Easy, >10,000). Drag-and-drop upload, optional crop/contrast/threshold filters, editable
   comparison text + size slider, and the font library side-by-side. All image handling stays in
   the browser; nothing is uploaded to a server. Honest copy: presented as a guided visual
   comparison aid, not automatic AI recognition.

2. **Q&A font finder wizard** (`/identify/`) — 5 questions (serif style, weight, mood, etc.),
   weighted scoring against 148 fonts, top-12 ranked results with match %, custom-text preview,
   links to font detail pages.

3. **Browse font library** (`/browse/`) — search + category/characteristic filters over 148
   curated Google Fonts, progressive font loading (loads the fonts you actually view),
   editable preview text and size control.

Supporting pages (162 total, all static):
- Homepage (`/`) targets "font identifier" (Hard, >10,000) + "free font identifier" (Easy, >100)
- 148 per-font detail pages (`/fonts/[slug]/`) with preview, characteristics, similar fonts
- 5 guides (`/guides/...`): identify-from-image how-to, free tools comparison,
  find-font-on-website how-to, font terms glossary + guides hub
- `/about/`, `/privacy-policy/`, `/terms-of-service/`, `/contact/`, custom 404
- Sitemap + robots.txt generated by Astro

## Keyword strategy applied
- "font identifier" / "free font identifier" → homepage
- "font identifier from image" → image tool page
- "adobe font identifier" → deliberately NOT targeted (brand term)
- "ai font identifier" → NOT marketed as AI; no recognition model is used
