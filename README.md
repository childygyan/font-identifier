# Font Identifier

Free font identifier and font finder — identify fonts from images with guided visual
comparison, answer 5 questions to get ranked matches, or browse 148 popular free fonts.

- **Stack:** Astro 5 + TypeScript (strict) + Tailwind CSS v4, fully static
- **Live:** https://font-identifier.pages.dev
- ** honest by design:** visual/question-based matching against a curated library — no fake "AI recognition" claims

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # -> dist/
```
